## How to launch

### Option A — Netlify (simple)
1. Create a Netlify account.
2. Choose **Add new site** / deploy manually.
3. Upload the contents of this folder.
4. Netlify gives you a temporary `*.netlify.app` address.
5. Later, connect a custom domain.

### Option B — GitHub Pages (free)
1. Create a GitHub account.
2. Create a new repository, e.g. `mr-chinonso-mathematics-academy`.
3. Upload `index.html`, `styles.css`, and `script.js`.
4. Open repository Settings → Pages.
5. Choose deployment from the main branch.
6. GitHub will provide the website address.

### Option C — Custom domain + professional hosting
Recommended once the academy is ready for serious marketing:
1. Buy a domain such as `mrchinonsomaths.com` (availability must be checked at the registrar).
2. Use a reputable static host such as Netlify, Vercel or GitHub Pages.
3. Connect the domain using the DNS records supplied by the host.
4. Enable HTTPS/SSL.
5. Add Google Search Console and Google Analytics only if you need analytics.
6. Create a professional email later, e.g. `hello@yourdomain.com`.
