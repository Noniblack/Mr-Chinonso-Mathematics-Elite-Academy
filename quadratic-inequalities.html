Lesson 1: Understanding Quadratic Inequalities

Start with the meaning of the symbols and the structure of a quadratic expression.

Learning objectives

By the end of this lesson, you should be able to:

  • Recognise and interpret quadratic inequalities.
  • Find the roots of the associated quadratic equation.
  • Use the roots to identify positive and negative intervals.
  • Distinguish strict inequalities from inclusive inequalities.
  • Present solutions correctly using inequalities and interval notation.

Know your inequality symbols

SymbolMeaningAre zero values included?
>Greater than zeroNo
<Less than zeroNo
≥Greater than or equal to zeroYes
≤Less than or equal to zeroYes

A quadratic inequality can be written in forms such as:

ax² + bx + c > 0 ax² + bx + c ≤ 0

Here, a ≠ 0. The expression has degree two.

Important: Solving an equation finds values that make an expression equal to zero. Solving an inequality finds all values that make it positive or negative as required.

Lesson 2: Roots and Sign Analysis

The roots divide the number line into intervals. The sign of the quadratic expression tells us which intervals to select.

Case A: Two distinct real roots and a positive leading coefficient

Suppose the expression is:

f(x) = (x − 2)(x − 3)

The roots are x = 2 and x = 3. Test the intervals on either side of and between the roots.

IntervalTest valueSign of f(x)
x < 2x = 0Positive
2 < x < 3x = 2.5Negative
x > 3x = 4Positive

Therefore, when the leading coefficient is positive and there are two distinct roots:

Positive outside the roots; negative between the roots.

Case B: Negative leading coefficient

If the quadratic has two distinct roots but its leading coefficient is negative, the signs reverse:

Negative outside the roots; positive between the roots.

General sign rule

For f(x) = a(x − r₁)(x − r₂), where r₁ < r₂:

  • If a > 0, f(x) is positive outside the roots and negative between them.
  • If a < 0, f(x) is negative outside the roots and positive between them.
If the quadratic has no real roots, its sign remains the same as the leading coefficient for every real x. If it has a repeated real root, its sign is the same as the leading coefficient on both sides of that root, except that the expression equals zero at the root.

Lesson 3: A Reliable Method for Solving

  1. Put the inequality in standard form. Move all terms to one side so that the other side is zero.
  2. Find the roots. Solve the associated quadratic equation by factorisation, completing the square or the quadratic formula.
  3. Arrange the roots. Place the smaller root before the larger root on a number line.
  4. Determine the sign. Use the leading coefficient and sign analysis, or test one value in each interval.
  5. Select the required interval or intervals. Choose where the expression satisfies the inequality.
  6. Check the endpoints. Include roots for ≥ or ≤; exclude roots for > or <.
  7. State the final answer clearly. Use inequality notation or interval notation.

Endpoint notation

  • (a, b) excludes both endpoints.
  • [a, b] includes both endpoints.
  • [a, b) includes a but excludes b.
  • (a, b] excludes a but includes b.

Lesson 4: Worked Examples

Study the method and the reason each interval is selected.

Example 1: Solve x² − 5x + 6 > 0

Step 1: Factorise.

(x − 2)(x − 3) > 0

Step 2: The roots are x = 2 and x = 3. The leading coefficient is positive, so the expression is positive outside the roots.

Answer:

x < 2 or x > 3

In interval notation: (−∞, 2) ∪ (3, ∞). The endpoints are excluded because the inequality is strict.

Example 2: Solve x² − 4x − 5 ≤ 0

Step 1: Factorise.

(x − 5)(x + 1) ≤ 0

The roots are x = −1 and x = 5. The leading coefficient is positive, so the expression is negative between the roots.

The inequality includes zero, so both roots are included.

−1 ≤ x ≤ 5

In interval notation: [−1, 5].

Example 3: Solve x² + 2x − 8 < 0

Step 1: Factorise.

(x + 4)(x − 2) < 0

The roots are x = −4 and x = 2. The leading coefficient is positive, so the expression is negative between the roots.

−4 < x < 2

In interval notation: (−4, 2).

Example 4: Solve −x² + 4x + 5 ≥ 0

Step 1: Find the roots.

−x² + 4x + 5 = 0

Multiply by −1 to obtain x² − 4x − 5 = 0. Factorising gives:

(x − 5)(x + 1) = 0

The roots are x = −1 and x = 5. The original expression has a negative leading coefficient, so it is positive between the roots.

Because zero is included:

−1 ≤ x ≤ 5

In interval notation: [−1, 5].

Multiplying an inequality by a negative number reverses its inequality symbol. In this example, we used multiplication by −1 only on the equation used to find the roots. We then returned to the original inequality to determine the signs.

Example 5: Solve 2x² − 8x + 6 > 0

Factorise:

2(x² − 4x + 3) > 0 2(x − 1)(x − 3) > 0

The roots are x = 1 and x = 3. The leading coefficient is positive, so the expression is positive outside the roots.

x < 1 or x > 3

In interval notation: (−∞, 1) ∪ (3, ∞).

Lesson 5: Guided Examination Practice

Attempt each question before opening its worked solution.

  1. Solve x² − 9x + 20 > 0.
    Reveal worked solution

    Factorise: (x − 4)(x − 5) > 0.

    The leading coefficient is positive, so select the intervals outside the roots.

    x < 4 or x > 5
  2. Solve x² − 3x − 4 ≤ 0.
    Reveal worked solution

    Factorise: (x − 4)(x + 1) ≤ 0.

    The expression is non-positive between the roots. Include both endpoints.

    −1 ≤ x ≤ 4
  3. Solve x² − 11x + 30 < 0.
    Reveal worked solution

    Factorise: (x − 5)(x − 6) < 0.

    The expression is negative between the roots. The endpoints are excluded.

    5 < x < 6
  4. Solve −x² + 6x − 8 > 0.
    Reveal worked solution

    Factorise: −(x − 2)(x − 4) > 0.

    The leading coefficient is negative, so the expression is positive between the roots.

    2 < x < 4
  5. Solve x² − 6x + 9 ≥ 0.
    Reveal worked solution

    Factorise: (x − 3)² ≥ 0.

    A square is never negative for real x. It equals zero at x = 3 and is positive everywhere else.

    All real numbers: x ∈ ℝ
  6. Solve x² + 4x + 8 > 0.
    Reveal worked solution

    The discriminant is b² − 4ac = 16 − 32 = −16, so there are no real roots.

    Since the leading coefficient is positive and there are no real roots, the quadratic is positive for every real x.

    All real numbers: x ∈ ℝ
