What is a quadratic equation?

METHODS OF SOLUTION

Four major routes to solving quadratic equations.

A strong learner should understand the reasoning behind each method and recognise when a method is useful.

1. Factorisation

Rewrite a suitable quadratic as a product of factors, then use the zero-product principle to determine the roots.

Best developed through pattern recognition and careful verification.
2. Completing the Square

Transform the quadratic into a perfect-square form. This method also provides a bridge to vertex form and graphical interpretation.

Especially useful for connecting algebraic and graphical ideas.
3. Quadratic Formula

For ax² + bx + c = 0, the quadratic formula provides a general method for finding the roots.

Useful when factorisation is difficult or unsuitable.
4. Graphical Solution

Interpret solutions through the points where a quadratic graph meets the x-axis, while connecting algebraic roots with graphical features.

Develops interpretation rather than relying only on symbolic manipulation.

Lesson 1: Foundations, objectives and prerequisites

1.1 Learning objectives

By the end of this lesson, students should be able to:

  • Define a quadratic equation and identify its degree.
  • Recognise the standard form ax² + bx + c = 0, where a ≠ 0.
  • Identify the coefficients a, b and c, including zero and negative coefficients.
  • Explain what is meant by a root or solution of an equation.
  • Use prerequisite algebra skills to prepare for solving quadratic equations.

1.2 Meaning of an equation

An equation is a mathematical statement that two expressions are equal. The symbol = means that the value on the left is equal to the value on the right.

Example: x + 4 = 9.

Subtract 4 from both sides:

x + 4 − 4 = 9 − 4

Therefore, x = 5.

The value x = 5 is called the solution because it makes the equation true.

1.3 What is a quadratic equation?

A quadratic equation is an equation that can be expressed as ax² + bx + c = 0, where a, b and c are constants and a ≠ 0. Its highest power of the variable is 2.

The terms are:

  • ax²: the quadratic term.
  • bx: the linear term.
  • c: the constant term.
  • a: the coefficient of x²; it must not be zero.

1.4 Worked Example 1: Identify the coefficients

Question: Identify a, b and c in 3x² − 7x + 2 = 0.

Step 1: Compare the equation with ax² + bx + c = 0.

Step 2: Read off the coefficients, including their signs.

Answer: a = 3, b = −7 and c = 2.

Important: The coefficient b is −7, not 7, because the term is −7x.

1.5 Worked Example 2: Recognise a missing term

Question: Identify a, b and c in 5x² − 20 = 0.

There is no term containing x. We can write the equation as 5x² + 0x − 20 = 0.

Answer: a = 5, b = 0 and c = −20.

A missing term has a coefficient of zero; it does not stop the equation from being quadratic.

1.6 Prerequisite revision

Skill A: Collect like terms

Example: 3x + 2x − 4 = 5x − 4.

Skill B: Expand brackets

Example: 2(x + 3) = 2x + 6.

Skill C: Use the zero-product property

If two factors multiply to give zero, at least one factor must be zero.

For example, (x − 2)(x − 5) = 0 gives x − 2 = 0 or x − 5 = 0. Hence x = 2 or x = 5.

Skill D: Solve a linear equation

Example: 4x − 8 = 12.

Add 8 to both sides: 4x = 20.

Divide both sides by 4: x = 5.

1.7 Common mistakes to avoid

  • Forgetting the negative sign when identifying a coefficient.
  • Assuming every equation containing x² is automatically in standard form.
  • Thinking a missing linear or constant term means the equation is not quadratic.
  • Changing only one side of an equation when performing the same operation on both sides is required.

1.8 Guided practice

Attempt these questions before revealing the answers.

Question 1: Identify the coefficients

For 4x² + 9x − 6 = 0, identify a, b and c.

Answer: a = 4, b = 9 and c = −6.

Question 2: Identify the missing coefficient

For 7x² − 49 = 0, state the values of a, b and c.

Answer: a = 7, b = 0 and c = −49.

Question 3: Solve a prerequisite equation

Solve 3x + 5 = 20.

Solution: Subtract 5 to obtain 3x = 15. Divide by 3.

Answer: x = 5.

1.9 Lesson summary

  • A quadratic equation has degree 2 and can be written as ax² + bx + c = 0, with a ≠ 0.
  • The coefficients may be positive, negative or zero for b and c.
  • A solution is a value that makes the equation true.
  • Expanding brackets, collecting like terms and solving simpler equations prepare students for quadratic methods.
Lesson 2: Recognising and classifying quadratic equations

2.1 Definition and standard form

A quadratic equation in one variable is an equation that can be written in the form:

ax² + bx + c = 0, where a ≠ 0.

Here, a, b and c are constants, and x is the variable. The highest power of x is 2, so the equation has degree 2.

  • Quadratic term: ax²
  • Linear term: bx
  • Constant term: c

The coefficient a must not be zero. If a = 0, the x² term disappears and the equation is no longer quadratic.

2.2 Worked Example 1: Identify the coefficients

Question: Identify a, b and c in 2x² − 5x + 3 = 0.

Step 1: Compare the equation with ax² + bx + c = 0.

Step 2: Identify each coefficient, retaining its sign.

Answer: a = 2, b = −5 and c = 3.

2.3 Worked Example 2: Convert to standard form

Question: Write 4x² + 7x = 9 in standard form.

Step 1: Subtract 9 from both sides.

4x² + 7x − 9 = 0

Answer: 4x² + 7x − 9 = 0, where a = 4, b = 7 and c = −9.

The equation was quadratic before rearrangement, but it was not yet written in standard form.

2.4 Worked Example 3: A missing linear term

Question: Express 3x² = 12 in standard form and identify the coefficients.

Step 1: Move 12 to the left side.

3x² − 12 = 0

Step 2: Include the missing linear term as 0x.

3x² + 0x − 12 = 0

Answer: a = 3, b = 0 and c = −12. The equation is still quadratic.

2.5 Worked Example 4: Classify the equation

Determine whether each equation is quadratic.

(a) 5x² − 2x + 1 = 0

The highest power is 2 and the coefficient of x² is 5, which is non-zero. It is quadratic.

(b) 6x − 11 = 0

The highest power is 1. It is linear, not quadratic.

(c) x³ + 2x − 4 = 0

The highest power is 3. It is cubic, not quadratic.

(d) 0x² + 4x − 8 = 0

The coefficient of x² is zero, so the equation reduces to 4x − 8 = 0. It is linear, not quadratic.

2.6 Important examination rules

  • Arrange the equation so that one side is zero before identifying a, b and c.
  • Keep the correct signs of all terms.
  • A missing term has a coefficient of zero.
  • The coefficient of x² must be non-zero for the equation to be quadratic.
  • Do not confuse an equation's degree with the number of terms it contains.

2.7 Guided practice

Try each question before expanding the answer.

Question 1: Identify the coefficients

For 6x² + x − 8 = 0, identify a, b and c.

Answer: a = 6, b = 1 and c = −8.

Question 2: Convert to standard form

Write 5x² − 3x = 10 in standard form.

Solution: Subtract 10 from both sides.

Answer: 5x² − 3x − 10 = 0.

Question 3: Recognise a missing term

For 8x² − 32 = 0, state a, b and c.

Answer: a = 8, b = 0 and c = −32.

Question 4: Classify the equation

Is 7x − 2 = 0 a quadratic equation? Explain.

Answer: No. It is linear because its highest power of x is 1.

2.8 Lesson summary

A quadratic equation has degree 2 and can be written as ax² + bx + c = 0, where a ≠ 0. Rearranging into standard form makes it easier to identify coefficients and choose a suitable solving method.

Lesson 3: Choosing and applying a solution method

Learning objectives

By the end of this lesson, students should be able to choose a suitable method for solving a quadratic equation, apply the method accurately, and check their answers.

1. Method A: Factorisation

Factorisation is often efficient when a quadratic expression can be written as a product of two linear factors.

Worked Example 1: Solve x² − 5x + 6 = 0.

  1. Find two numbers whose product is 6 and whose sum is −5: −2 and −3.
  2. Factorise: (x − 2)(x − 3) = 0.
  3. Apply the zero-product property: x − 2 = 0 or x − 3 = 0.
  4. Therefore, x = 2 or x = 3.

Key principle: If AB = 0, then A = 0 or B = 0.

2. Method B: Completing the square

Completing the square rewrites a quadratic expression as a perfect square plus or minus a constant. It is especially useful when factorisation is inconvenient.

Worked Example 2: Solve x² + 6x + 5 = 0.

  1. Move the constant: x² + 6x = −5.
  2. Take half the coefficient of x: 6 ÷ 2 = 3. Square it: 3² = 9.
  3. Add 9 to both sides: x² + 6x + 9 = 4.
  4. Write the left side as a perfect square: (x + 3)² = 4.
  5. Take square roots: x + 3 = ±2.
  6. Hence x = −3 + 2 or x = −3 − 2.
  7. Therefore, x = −1 or x = −5.

Important: Whatever you add to one side of an equation must also be added to the other side.

3. Method C: The quadratic formula

The quadratic formula works for every quadratic equation written as ax² + bx + c = 0, provided a ≠ 0. Identify a, b and c carefully, including their signs.

Worked Example 3: Solve 2x² + x − 3 = 0.

  1. Identify the coefficients: a = 2, b = 1 and c = −3.
  2. Use the quadratic formula: x = (−b ± √(b² − 4ac)) ÷ 2a.
  3. Substitute a = 2, b = 1 and c = −3: x = (−1 ± √25) ÷ 4.
  4. Evaluate the discriminant: b² − 4ac = 1² − 4(2)(−3) = 25.
  5. Evaluate: x = (−1 ± 5) ÷ 4.
  6. First root: x = (−1 + 5) ÷ 4 = 1.
  7. Second root: x = (−1 − 5) ÷ 4 = −3/2.
  8. Therefore, x = 1 or x = −3/2.

4. How to choose the best method

  • Factorisation: Try this first when the factors are easy to identify.
  • Completing the square: Use it when you need a perfect-square form or want to understand the derivation of the quadratic formula.
  • Quadratic formula: Use it when factorisation is difficult or you need a dependable general method.

Always follow the method required by an examination question. If no method is specified, choose a valid method and show the essential working.

5. Guided practice

Practice A: Solve x² − 7x + 12 = 0 by factorisation.

Find two numbers with product 12 and sum −7: −3 and −4.

(x − 3)(x − 4) = 0.

Answer: x = 3 or x = 4.

Practice B: Solve x² + 4x − 1 = 0 by completing the square.

x² + 4x = 1.

Add (4 ÷ 2)² = 4 to both sides: x² + 4x + 4 = 5.

(x + 2)² = 5, so x + 2 = ±√5.

Answer: x = −2 ± √5.

Practice C: Solve 3x² − 2x − 1 = 0 using the quadratic formula.

a = 3, b = −2 and c = −1.

The discriminant is (−2)² − 4(3)(−1) = 16.

x = (2 ± √16) ÷ 6 = (2 ± 4) ÷ 6.

Answer: x = 1 or x = −1/3.

Common errors to avoid

  • Forgetting to set the equation equal to zero before factorising.
  • Using incorrect signs when identifying a, b and c.
  • Forgetting the ± sign when taking square roots.
  • Adding a number to only one side while completing the square.
  • Giving only one root when two distinct roots exist.

Lesson summary: Select a suitable method, show each important step, obtain all roots, and substitute your answers into the original equation to check them.

Lesson 4: Checking solutions and interpreting answers

Learning objectives

By the end of this lesson, students should be able to verify solutions by substitution, identify invalid answers, interpret roots in context, and communicate final answers with appropriate units.

1. Checking a solution by substitution

A solution of an equation is a value that makes the equation true. To check a proposed root, substitute it into the original equation and simplify both sides.

Worked Example 1: Verify that x = 2 and x = 3 are solutions of x² − 5x + 6 = 0.

Check x = 2:

Substitute x = 2:

2² − 5(2) + 6 = 4 − 10 + 6 = 0.

The equation is satisfied, so x = 2 is a solution.

Check x = 3:

Substitute x = 3:

3² − 5(3) + 6 = 9 − 15 + 6 = 0.

The equation is satisfied, so x = 3 is also a solution.

Conclusion: Both roots are correct.

2. Distinguishing valid and invalid proposed solutions

A value that does not satisfy the original equation is not a solution, even if it appears during an incorrect calculation.

Worked Example 2: Is x = 4 a solution of x² − 5x + 6 = 0?

Substitute x = 4:

4² − 5(4) + 6 = 16 − 20 + 6 = 2.

Since 2 ≠ 0, x = 4 is not a solution.

Checking tip: Always check proposed roots in the original equation, not merely in a rearranged expression that may contain an error.

3. Interpreting roots in word problems

Quadratic equations can produce two mathematical roots, but the context of a problem determines which roots are meaningful. Lengths, ages in a specified setting, and numbers of objects usually cannot be negative.

Worked Example 3: A rectangle has a width of x cm and a length of (x + 3) cm. Its area is 54 cm². Find its dimensions.

  1. Form the equation: x(x + 3) = 54.
  2. Expand and rearrange: x² + 3x − 54 = 0.
  3. Factorise: (x + 9)(x − 6) = 0.
  4. Find the roots: x = −9 or x = 6.
  5. Interpret the results: a width of −9 cm is impossible, so reject it.
  6. Use x = 6: width = 6 cm and length = 6 + 3 = 9 cm.

Answer: The rectangle is 6 cm wide and 9 cm long. Check: 6 × 9 = 54 cm².

4. Checking answers in context

After solving a word problem, check both the mathematics and the meaning of the answer.

  • Lengths and distances: Reject negative values when they represent actual lengths or distances.
  • Numbers of people or objects: The answer must be a non-negative whole number.
  • Time: Check whether the value fits the time interval described in the question.
  • Units: Include units such as cm, m, seconds, or square metres where appropriate.
  • Original conditions: Confirm that the accepted value satisfies the equation and the word problem.

5. Guided practice

Practice A: Check whether x = 4 is a solution of x² − 7x + 12 = 0.

Substitute x = 4:

4² − 7(4) + 12 = 16 − 28 + 12 = 0.

Answer: Yes. x = 4 is a solution because the expression equals zero.

Practice B: Check whether x = 2 is a solution of x² + 4x − 1 = 0.

Substitute x = 2:

2² + 4(2) − 1 = 4 + 8 − 1 = 11.

Since 11 ≠ 0, x = 2 is not a solution.

Practice C: A rectangle has width x m, length (x + 2) m and area 24 m². Find its dimensions.

Form the equation: x(x + 2) = 24.

Rearrange: x² + 2x − 24 = 0.

Factorise: (x + 6)(x − 4) = 0.

Therefore, x = −6 or x = 4. Reject x = −6 because a width cannot be negative.

Width = 4 m; length = 4 + 2 = 6 m.

Answer: 4 m by 6 m. Check: 4 × 6 = 24 m².

Common examination errors

  • Checking only one root when two roots have been obtained.
  • Making arithmetic errors during substitution.
  • Accepting a negative length or another impossible contextual answer.
  • Giving a numerical answer without the required units.
  • Failing to state why a root has been rejected.

Lesson summary: Solve the equation, substitute roots into the original equation, reject values that do not satisfy the problem's conditions, and state the final answer clearly with appropriate units.

Lesson 5: Examination mastery and problem-solving strategy

Learning objectives

By the end of this lesson, students should be able to approach quadratic-equation questions systematically, select an efficient method, present complete mathematical working, check their answers, and interpret results correctly.

1. The five-step examination strategy

  1. Read carefully: Identify what the question asks you to find and whether a particular method is required.
  2. Arrange the equation: Where appropriate, write it in standard form, ax² + bx + c = 0, with a ≠ 0.
  3. Choose a method: Use factorisation when convenient, completing the square when appropriate, or the quadratic formula when a general method is needed.
  4. Show the working: Write the important algebraic steps clearly, including both roots when applicable.
  5. Check and conclude: Verify the roots by substitution and interpret the result in context where necessary.

2. Worked examination question: Factorisation

Question: Solve 2x² − 7x + 3 = 0.

Step 1: Multiply the coefficient of x² by the constant term: 2 × 3 = 6.

Step 2: Find two numbers whose product is 6 and whose sum is −7: −6 and −1.

Step 3: Split the middle term:

2x² − 6x − x + 3 = 0.

Step 4: Factorise by grouping:

2x(x − 3) − 1(x − 3) = 0.

(2x − 1)(x − 3) = 0.

Step 5: Apply the zero-product property:

2x − 1 = 0 or x − 3 = 0.

Answer: x = 1/2 or x = 3.

3. Verify both roots

Check x = 1/2:

2(1/2)² − 7(1/2) + 3 = 1/2 − 7/2 + 3 = 0.

Check x = 3:

2(3)² − 7(3) + 3 = 18 − 21 + 3 = 0.

Both roots satisfy the original equation.

4. Examination presentation and time management

  • Write the equation clearly and show the main steps rather than jumping straight to the answer.
  • Keep negative signs, brackets, fractions, and square roots accurate.
  • Do not assume that every quadratic equation has two distinct real roots.
  • Follow the instruction if the question specifies a method.
  • Allocate time according to the marks and difficulty of each question.
  • Leave time to check arithmetic, roots, units, and the final statement.

Marking advice: In written examinations, clear method and intermediate working can help an examiner identify correct steps even if an arithmetic error occurs later. Actual mark allocation depends on the examination and its marking scheme.

5. Common examination traps

  • Failing to rearrange an equation into standard form before applying a method that requires it.
  • Making a sign error when identifying a, b, or c.
  • Forgetting one root after factorising.
  • Dropping the ± sign when taking square roots or using the quadratic formula.
  • Accepting a negative length or another value that contradicts the question's context.
  • Leaving out units or failing to state the final answer.

6. Timed examination practice

Try the following questions before opening their solutions. Suggested practice time: 6 minutes in total. This is a training target, not an official examination timing rule.

Question A: Solve x² − 9x + 20 = 0.

Find two numbers with product 20 and sum −9: −4 and −5.

(x − 4)(x − 5) = 0.

Answer: x = 4 or x = 5.

Check: 4² − 9(4) + 20 = 0 and 5² − 9(5) + 20 = 0.

Question B: Solve 2x² + x − 4 = 0 using the quadratic formula.

a = 2, b = 1 and c = −4.

Discriminant: b² − 4ac = 1 − 4(2)(−4) = 33.

x = (−1 ± √33) ÷ 4.

Answer: x = (−1 + √33)/4 or x = (−1 − √33)/4.

Since 33 is not a perfect square, the roots are irrational real numbers.

Question C: A rectangle has width x m, length (x + 4) m and area 45 m². Find its dimensions.

x(x + 4) = 45.

x² + 4x − 45 = 0.

(x + 9)(x − 5) = 0, so x = −9 or x = 5.

Reject x = −9 because a width cannot be negative.

Answer: Width = 5 m and length = 9 m.

Check: 5 × 9 = 45 m².

7. Final mastery checklist

  • I can recognise a quadratic equation and write it in standard form.
  • I can choose and apply a suitable solving method.
  • I can calculate and state both roots when appropriate.
  • I can verify roots by substitution.
  • I can reject answers that are impossible in a real-life context.
  • I can show clear working and state the final answer accurately.

Lesson summary: Examination success comes from understanding the mathematics, selecting an appropriate method, presenting complete working, checking results, and answering exactly what the question asks.

✏️ Worked Examples

Follow each solution carefully. Expand your understanding from basic equations to more challenging applications.

Example 1: Solve by factorisation

Question: Solve \(x^2 - 5x + 6 = 0\).

Step 1: Find two numbers whose product is 6 and whose sum is −5. They are −2 and −3.

Step 2: Factorise the equation:

\((x - 2)(x - 3) = 0\)

Step 3: Set each factor to zero:

\(x - 2 = 0\) or \(x - 3 = 0\).

Answer: \(x = 2\) or \(x = 3\).

Check: Both values make the original expression equal to zero.

Example 2: Complete the square

Question: Solve \(x^2 + 6x + 5 = 0\).

Step 1: Move the constant:

\(x^2 + 6x = -5\)

Step 2: Half the coefficient of \(x\) is 3; its square is 9. Add 9 to both sides:

\(x^2 + 6x + 9 = 4\)

Step 3: Write the left side as a perfect square:

\((x + 3)^2 = 4\)

Step 4: Take both square roots:

\(x + 3 = \pm 2\)

Therefore, \(x = -1\) or \(x = -5\).

Answer: \(x = -1\) or \(x = -5\).

Example 3: Use the quadratic formula

Question: Solve \(2x^2 + x - 3 = 0\).

Step 1: Identify \(a = 2\), \(b = 1\), and \(c = -3\).

Step 2: Substitute into the formula:

\(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)

\(x = \frac{-1 \pm \sqrt{1 - 4(2)(-3)}}{4}\)

\(x = \frac{-1 \pm \sqrt{25}}{4}\)

Step 3: Evaluate both possibilities:

\(x = \frac{-1 + 5}{4} = 1\)

\(x = \frac{-1 - 5}{4} = -\frac{3}{2}\)

Answer: \(x = 1\) or \(x = -\frac{3}{2}\).

Quadratic Equations in Practical Problems

Learn how to translate real-life situations into quadratic equations, solve them systematically, and interpret the answers in context. These are original examination-style practice examples, not claimed past WAEC questions.

WORKED EXAMPLE 1

Finding the dimensions of a rectangle

The length of a rectangle is 3 cm greater than its width. If its area is 54 cm², find its dimensions.

Step 1: Define the variable

Let the width be x cm. Then the length is (x + 3) cm.

Step 2: Form the quadratic equation

Area = length × width
x(x + 3) = 54
x² + 3x − 54 = 0

Step 3: Solve by factorisation

(x + 9)(x − 6) = 0
Therefore, x = −9 or x = 6.

Step 4: Interpret the answer

A dimension cannot be negative, so the width is 6 cm. The length is 6 + 3 = 9 cm.

Answer: Width = 6 cm; length = 9 cm.

Check: 6 × 9 = 54 cm².

WORKED EXAMPLE 2

Two consecutive positive integers

The product of two consecutive positive integers is 72. Find the integers.

Step 1: Represent the integers

Let the smaller integer be n. The next integer is n + 1.

Step 2: Form the equation

n(n + 1) = 72
n² + n − 72 = 0

Step 3: Factorise

(n + 9)(n − 8) = 0
Therefore, n = −9 or n = 8.

Step 4: Select the valid integers

Since both integers must be positive, n = 8. The next integer is 9.

Answer: 8 and 9.

Check: 8 × 9 = 72.

INDEPENDENT PRACTICE

Test your understanding

Question 1: The length of a rectangle is 5 cm greater than its width. Its area is 84 cm². Find its dimensions.

Reveal answer to Question 1

Let the width be x. Then x(x + 5) = 84, giving x² + 5x − 84 = 0. Factorising gives (x + 12)(x − 7) = 0. The width is 7 cm and the length is 12 cm.

Question 2: The product of two consecutive positive integers is 156. Find the integers.

Reveal answer to Question 2

Let the smaller integer be n. Then n(n + 1) = 156, so n² + n − 156 = 0. Factorising gives (n + 13)(n − 12) = 0. The integers are 12 and 13.

Question 3: A number multiplied by the number that is 4 greater than it gives 96. Find the positive number.

Reveal answer to Question 3

Let the number be x. Then x(x + 4) = 96, so x² + 4x − 96 = 0. Factorising gives (x + 12)(x − 8) = 0. The positive number is 8.

    Quadratic Equations FAQ

    What makes an equation quadratic?

    Its highest power of the variable is 2, and it can be represented in the standard form ax² + bx + c = 0 with a ≠ 0.

    Which method should I use to solve a quadratic equation?

    It depends on the structure of the equation. A strong learner should be able to recognise suitable methods and verify the resulting solutions.

    Is completing the square useful beyond solving equations?

    Yes. It provides an important connection between quadratic equations, perfect squares, vertex form and graphical interpretation.

    Can quadratic equations be used in examination preparation?

    Yes. The mathematical concepts can be developed through progressively challenging practice and then applied to the relevant requirements of an examination pathway.
